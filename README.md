## 專案目的

這項實驗想了解，當學生可以使用成熟的 AI 工具時，原本以手寫 Verilog 為主的作業，能在多大程度上交由 AI 完成。實作由 Codex 執行；使用者透過文字指令提出需求、選擇方案、要求驗證並監督結果。

主要關注以下幾件事：

1. **完成作業的能力與投入成本**：觀察 Codex 能否完成這類複雜度的 RTL 作業，並記錄使用的模型、Token 用量、執行時間與人工介入情形，評估實際需要多少投入。
2. **追求效能排名時的設計取捨**：觀察 AI 是否會為了壓低執行週期數，提出大量平行運算等極端設計，並討論這些做法的資源需求、驗證負擔與實務價值。
3. **測試結果與正式評分的對照**：保留各階段的正確性測試、效能數據與 lint（靜態 RTL 規則檢查）結果；待官方成績與排名公布後，再補上結果並討論差異。
4. **課程調整的依據**：根據實際完成過程與評分結果，討論 CVSD 的作業內容、評量方式與學習目標，在 AI 工具普及後可以如何調整。

各次作業完成後會逐步更新紀錄；等全部作業完成，再彙整實驗資料，作為研究文章的基礎。
